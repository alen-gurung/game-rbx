# Lighting, materials and mood

Whole-scene color, value, atmosphere, material relationships and separation of the focal toy from its background.

**Scope:** No final palette or lighting direction is approved. This is a place to collect comparisons.

## Current references

No dedicated reference files collected yet.

## What to record

Record camera/viewport and graphics settings when known. Study key/feet/obstacle readability and low-quality fallback. An attractive reference is not a universal preset or evidence of the exact settings used. Individual object material detail can stay with its model.

Keep each original file in one primary folder and link to it from related categories. Record source/provenance, the specific detail to study and its approval status using the [reference guide](../../README.md). This folder is a reference collection, not a runtime asset or gameplay implementation.
