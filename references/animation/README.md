## What to record

Prefer source links with useful timestamps, normal-speed playback and clear event beats; note if a clip is staged or edited. Distinguish model/rig form from motion. Do not split into locomotion, interactions and endings until there is enough material. Still poses cannot establish timing or a clean loop.

Keep each original file in one primary folder and link to it from related categories. Record source/provenance, the specific detail to study and its approval status using the [reference guide](../README.md). This folder is a reference collection, not a runtime asset or gameplay implementation.
