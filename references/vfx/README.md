# Visual-effect references

Particles, trails, impacts, gain bursts and other transient effects tied to a visible event.

**Scope:** Optional presentation references; no new VFX system or asset is approved by this folder.

## Current references

No dedicated reference files collected yet.

## What to record

Record trigger, lifetime, focal point, visibility against the real scene and overlap/readability concerns. Persistent lighting belongs in environments; reusable UI styling belongs in ui/components. An effect must not hide the toy or become the sole required signal.

Keep each original file in one primary folder and link to it from related categories. Record source/provenance, the specific detail to study and its approval status using the [reference guide](../README.md). This folder is a reference collection, not a runtime asset or gameplay implementation.
