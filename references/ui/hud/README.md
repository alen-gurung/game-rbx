In-play counters, Power/Level displays, remaining-wind meters, current objectives, navigation and persistent status indicators.

**Scope:** Relevant to GAME-001–GAME-007 as introduced by each story; no final HUD artwork approved.

## Current references

- See [full-screen composition](../full-screens/README.md) and [training feedback](../training/README.md). These are linked originals; no dedicated HUD crops have been collected.

## What to record

Capture large values, long labels, low-wind state, safe areas and desktop/phone readability. Put a complete composition in full-screens; a reusable individual control belongs in components.

Keep each original file in one primary folder and link to it from related categories. Record source/provenance, the specific detail to study and its approval status using the [reference guide](../../README.md). This folder is a reference collection, not a runtime asset or gameplay implementation.
