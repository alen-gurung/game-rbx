# Full-screen UI

Complete gameplay screens used to study overall composition: HUD placement, visual hierarchy, modal layering and the space left for the game.

**Scope:** General composition references only; no final HUD direction is approved.

## Current references

- [Simulator HUD overview](<Screenshot 2026-10-03 025316.png>) — Level/progression bar, counters, navigation and premium offers surround the scene. The density, pets, shops and offline earnings are not approved game features. A visible Shop or Inventory button does not show the design of that panel.

## What to record

Record viewport, device/orientation, visible UI state and the region being studied. A full-size screenshot focused on one feature can live with that feature; image dimensions alone do not determine its folder.

Keep each original file in one primary folder and link to it from related categories. Record source/provenance, the specific detail to study and its approval status using the [reference guide](../../README.md). This folder is a reference collection, not a runtime asset or gameplay implementation.
