# Decorative props and environment pieces

Supporting furniture, set dressing, signs, trim and reusable environment pieces that are not the main toy or a gameplay obstacle.

**Scope:** Decoration follows a readable blockout; this folder does not add a decoration milestone.

## Current references

No dedicated reference files collected yet.

## What to record

Record scale, material role and whether collision is intended. A prop with a gameplay role belongs to the appropriate interactable/obstacle category. Keep important travel and camera space clear.

Keep each original file in one primary folder and link to it from related categories. Record source/provenance, the specific detail to study and its approval status using the [reference guide](../../README.md). This folder is a reference collection, not a runtime asset or gameplay implementation.
