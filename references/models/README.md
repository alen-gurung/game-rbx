# Model references

Use these folders for the form and material of individual 3D objects: images, sketches, turntable links and dimensions when actually known. No production models or approved source assets have been added.

- [Toys and characters](toys-and-characters/README.md): Silhouettes, proportions, shape language, key/feet details and material studies for the focal toy or a relevant character.
- [Training stations and interactable props](training-stations/README.md): Bench form, the small toy placement, hand/key access and physical affordances for training.
- [Obstacle models](obstacles/README.md): Ramp, step and loose-block forms; contact surfaces and shape readability along the course.
- [Decorative props and environment pieces](props/README.md): Supporting furniture, set dressing, signs, trim and reusable environment pieces that are not the main toy or a gameplay obstacle.

An entire map belongs in environments; motion belongs in animation. Textures/material samples can stay beside the object they describe until a shared material library is needed. Do not create a folder for every possible Roblox asset type before there is a purpose.

Editable models, licensed imports, exports and Roblox asset IDs need a separate production source/manifest workflow when assets are made. The reference library does not replace that workflow or establish reuse permission.
