## What to record

Identify intended role and distinguish observed dimensions from estimates. Form references do not prove pivots, collision or rigging. Gaits/poses belong in animation. No approved duck model or character artwork has been collected.

Keep each original file in one primary folder and link to it from related categories. Record source/provenance, the specific detail to study and its approval status using the [reference guide](../../README.md). This folder is a reference collection, not a runtime asset or gameplay implementation.
